# Information Architecture (IA) Skill Suite

A comprehensive, modular, and installable suite of **AI Agent Skills and automation CLI tools** dedicated to **Information Architecture (IA)** for modern AI coding assistants (Google Antigravity, Claude Code, Cursor, Gemini CLI, GitHub Copilot).

This project implements the normative specifications:
- [Information Architecture — Global Documentation](./specs/documentation-architecture-information.md)
- [Part 1: Arborescence Specification (v0.4)](./specs/spec-arborescence.md)
- [Part 2: Userflows Specification (v2.2)](./specs/spec-userflows.md)

---

> [!IMPORTANT]
> **Language Rule for Deliverables:**
> All skill instructions, frameworks, and templates are maintained in English. However, **all project deliverables generated by these skills (reference tables, user journey files, screen sheets, audit reports, QA/UAT test plans, tracking plans, diagram labels, and functional notes) MUST be produced in the language used by the user in their prompt or conversation** (e.g., if the user prompts in French, produce all deliverables in French; if in English, produce in English; if in Spanish, German, etc., produce in that language). Formal technical tokens (e.g., `HOME`, `L001`, `C001:EDIT`, `FEAT-xxx`, `ND-xxx`, `!`, `#`, `⏸`, `key=VALUE`) remain unlocalized.

## 1. Skills Overview

The suite comprises **8 modular skills** following a logical, scopable workflow:

| Skill | Role | Trigger / Usage |
| :--- | :--- | :--- |
| [`ia-orchestrator`](./skills/ia-orchestrator/SKILL.md) | **Master Orchestrator** | Coordinates end-to-end IA steps; handles global or scoped use case slicing. |
| [`ia-cadrage`](./skills/ia-cadrage/SKILL.md) | **Scoping & Extraction** | Use when specifications are incomplete, informal, or raw (brief, PRD, existing code). |
| [`ia-arborescence`](./skills/ia-arborescence/SKILL.md) | **Part 1: Arborescence** | Models reference tables (`pages`, `variantes`, `modules`, `composants_page`, `renvois`, `roles`) and canonical cascading URLs. |
| [`ia-userflows`](./skills/ia-userflows/SKILL.md) | **Part 2: Userflows** | Formalizes journeys (`UC-xxx.md`), nominal flows, variants (`diverge_de`/`rejoint`), segments, flow breaks `⏸`, and closed context. |
| [`ia-fiches-ecran`](./skills/ia-fiches-ecran/SKILL.md) | **Deduced Screen Sheets** | Generates detailed cross-cutting screen inventories for every screen (Section 7). |
| [`ia-tracking`](./skills/ia-tracking/SKILL.md) | **Tracking Plan** | Instruments conversion funnels, custom analytics events, and return keys (Section 5). |
| [`ia-qa-uat`](./skills/ia-qa-uat/SKILL.md) | **QA & UAT Test Plans** | Step-by-step test suites, context assertions, confidence status progression (Section 6). |
| [`ia-audit`](./skills/ia-audit/SKILL.md) | **Audit & Consistency** | Automated detection of broken links, grammar violations, and normative rules (C1-C15, R-01-R-72). |

## 2. Installation & Quickstart

### 2.1 Recommended: Global Python CLI Installation
Make the `ia-tools` command (and `ia_tools` Python module) accessible globally across your environment and agents:
```bash
# In repository root:
pip install -e .
```
Or automatically via the standalone installer:
```bash
python installer/install.py --pip
```

### 2.2 Google Antigravity: Complete Plugin Deployment (Recommended)
Deploys the full bundle (8 skills, Python tools, templates, specs) as a single Antigravity plugin:
```bash
# In workspace (.agents/plugins/information-architecture):
python installer/install.py --target antigravity --as-plugin

# Globally for user (~/.gemini/antigravity/plugins/information-architecture):
python installer/install.py --target antigravity --as-plugin --global
```

### 2.3 Individual Skills Deployment (Multi-Agent Environments)
A standalone Python installation script (stdlib only, zero dependencies) links or copies skills to your agent environments:

```bash
# Antigravity individual skills (.agents/skills)
python installer/install.py --target antigravity

# Claude Code (.claude/skills)
python installer/install.py --target claude

# Cursor (.cursor/skills)
python installer/install.py --target cursor

# Gemini CLI (.gemini/skills)
python installer/install.py --target gemini

# GitHub Copilot (.github/skills)
python installer/install.py --target copilot

# Deploy to all supported targets with pip install
python installer/install.py --target all --pip

# Dry-run mode
python installer/install.py --dry-run --target all
```

## 3. Automation CLI Tools (`ia-tools` / `ia_tools`)

The package provides validation, scaffolding, synchronization, and generation engines executable either via the `ia-tools` CLI command or `python -m ia_tools.cli`:

### 3.0 Initialize a Project (`init`)
Deploys normative arborescence tables and templates directly into a new or existing workspace:
```bash
# Minimal scaffolding (pages, modules, registry, UC template)
ia-tools init --dir .

# Full scaffolding (includes tracking, QA/UAT, and audit templates)
ia-tools init --dir . --mode full
```

### 3.1 Validation & Consistency Audit
Audits arborescence integrity checks (C1 to C15) and userflow rules (R-01 to R-72) with automatic broken link detection:
```bash
# Full project audit
ia-tools validate --dir .

# Scoped audit on a specific use case
ia-tools validate --dir . --scope UC-DOSSIER

# Export Markdown report
ia-tools validate --dir . --output rapport-audit.md
```

### 3.2 Synchronize Registry
Updates `registre/pages.md`, `registre/modules.md`, and `registre/roles.md` from arborescence reference tables:
```bash
python -m ia_tools.cli sync-registry --dir . --out registre
```

### 3.3 Generate Mermaid Diagrams
Generates `flowchart TD` (sitemap overview, detailed) and `flowchart LR` (userflow overview, collapsed, expanded) with frontmatter metadata and a single unified interactive HTML preview:
```bash
python -m ia_tools.cli generate-mermaid --dir . --out generated --preview
```

### 3.4 Extract Screen Sheets
Extracts synthetic cross-cutting sheets for every identified screen:
```bash
python -m ia_tools.cli extract-screens --dir . --out generated/screen-sheets
```

## 4. Templates Catalog (`templates/`)

Pre-built templates are available in [`templates/`](./templates/):
