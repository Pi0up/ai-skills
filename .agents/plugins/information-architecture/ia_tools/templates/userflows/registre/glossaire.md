# Context Glossary — Closed Vocabulary for Userflows

> Declares the closed vocabulary used to specify input and output contexts (`key=VALUE`).
> Conforms to spec-userflows.md (Section 2.3).
> Keys in lowercase (`a-z0-9_`), values in uppercase (`A-Z0-9_`), separated by ' ; '.

| Family | Key | Example Values |
| :--- | :--- | :--- |
| Business entity & state | folder | DRAFT, READY, SUBMITTED, VALID, REJECTED |
| Business entity & state | attachments | EMPTY, UPLOADED, IN_REVIEW, VALID |
| User origin | origin | HOME, SEARCH, NOTIFICATION, DIRECT_LINK |
| Available data | data | COMPLETE, MISSING_ATTACHMENT, INPUT_ERROR |
| Expertise level | level | BEGINNER, EXPERT |
| Support status | assistance | REQUESTED, IN_PROGRESS, RESOLVED |
