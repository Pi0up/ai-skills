# Fiche d'Écran : D001 (Tableau de Bord Client & Admin)

- **Code canonique** : `D001`
- **Template** : Dashboard (`type=D`, `subtype=dashboard`)
- **URL** : `/dashboard`
- **Accès** : `protected`
- **Rôles habilités** : `CLIENT`, `ADMIN`
- **Tags** : `SP1`

## 1. Description fonctionnelle
Espace de gestion des réservations passées et à venir, factures téléchargeables et statistiques d'occupation pour les gestionnaires.

## 2. Éléments clés de l'interface
- KPI : nombre de réservations en cours, dépenses / recettes du mois
- Tableau interactif des réservations avec filtres par statut
- Actions rapides : annuler, reporter, télécharger la facture PDF
